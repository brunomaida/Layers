# Undo/redo global (S2.13) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ctrl+Z desfaz e Ctrl+Shift+Z / Ctrl+Y refaz os ajustes de propriedade e de código ainda não gravados, com toast por passo.

**Architecture:** Snapshot de `changes[]` antes de cada mutação, em duas pilhas de instância (`undoS`, `redoS`, 100 passos). A diferença entre dois snapshots vira escritas de estilo inline por uma função pura (`LayersCore.inlineDelta`), testável sem DOM. Câmera, seleção e layout ficam fora.

**Tech Stack:** HTML + JS puro em `index.html`, `lib/layers-core.js` (classic script, ES5), Vitest (`npm test`), Playwright (`npm run test:e2e`).

**Spec:** [`docs/superpowers/specs/2026-10-14-s2-13-undo-redo-design.md`](../specs/2026-10-14-s2-13-undo-redo-design.md)

## Global Constraints

- Visual congelado: nenhum botão, item de menu ou mudança de dock/painel; só teclado e toast (CLAUDE.md, escolha do usuário).
- `index.html` é arquivo único: edite com âncoras únicas e confira a contagem de matches antes de substituir; estilo inline; `support.js` não se edita.

## Review Focus

Entradas que o spec implica e nenhuma tarefa de teste cobriria sozinha, mais prováveis primeiro:

1. Ctrl+Z com a pergunta de escopo (`pending`) aberta: nada acontece e nenhum toast "Desfeito" aparece (Task 2, teste `Undo_PendingScopeQuestion_DoesNothing`).
2. Desfazer um ajuste de escopo "Todos iguais" restaura todos os ids estendidos, não só o selecionado (Task 1 `InlineDelta_EscopoAll_RestauraTodosOsIds`; Task 2 `Undo_AllScopeEdit_RestoresEveryExtendedId`).
3. Reaplicar o mesmo valor não cria passo fantasma: um único Ctrl+Z volta ao original (Task 2, `Undo_OneScopeEdit_RestoresInlineAndRedoReapplies`).
4. Nova edição depois de um undo invalida o redo (mesmo teste, trecho final).
5. Foco em `input`: Ctrl+Z não dispara o undo global (Task 2, `Undo_FocusInTextField_LeavesAppliedEditAlone`).

- [ ] **Step 3: Write minimal implementation**

Em `lib/layers-core.js`, logo após a função `hasUnsaved` (termina em `return (changes || []).length > 0 || Object.keys(codeBuf || {}).length > 0;\n  }`), insira:

```js
  // Inline style writes that take the change list `cur` to `target`: [{ id, prop, value }].
  function inlineDelta(cur, target) {
    var out = [], seen = {};
    (target || []).forEach(function (c) {
      c.ids.forEach(function (id) { seen[id + '|' + c.prop] = 1; out.push({ id: id, prop: c.prop, value: c.to }); });
    });
    (cur || []).forEach(function (c) {
      c.ids.forEach(function (id) { if (!seen[id + '|' + c.prop]) out.push({ id: id, prop: c.prop, value: c.fromInline[id] || '' }); });
    });
    return out;
  }

  // New stack with `snap` on top, oldest entries dropped past `cap`; never mutates `stack`.
  function pushSnapshot(stack, snap, cap) {
    var next = (stack || []).concat([snap]);
    return next.length > cap ? next.slice(next.length - cap) : next;
  }
```

E na lista de exports, após a linha `    hasUnsaved: hasUnsaved,`, acrescente:

```js
    inlineDelta: inlineDelta,
    pushSnapshot: pushSnapshot,
```

test('Undo_OneScopeEdit_RestoresInlineAndRedoReapplies', async ({ page }) => {

  pushUndo() { this.undoS = LayersCore.pushSnapshot(this.undoS, this.cloneChanges(), UNDO_CAP); this.redoS = []; }
  resetUndo() { this.undoS = []; this.redoS = []; }
  undo() { this.stepHistory(true); }
  redo() { this.stepHistory(false); }
  stepHistory(back) {
    if (this.state.pending) return;
    const from = (back ? this.undoS : this.redoS) || [];
    if (!from.length) { this.toast(back ? 'Nada para desfazer' : 'Nada para refazer', 'ok'); return; }
    const target = from[from.length - 1]; const cur = this.cloneChanges(); const rest = from.slice(0, -1);
    if (back) { this.undoS = rest; this.redoS = LayersCore.pushSnapshot(this.redoS, cur, UNDO_CAP); } else { this.redoS = rest; this.undoS = LayersCore.pushSnapshot(this.undoS, cur, UNDO_CAP); }
    const delta = LayersCore.inlineDelta(cur, target);
    delta.forEach(d => { const e2 = this.els[d.id]; if (e2) e2.style[d.prop] = d.value; });
    const props = [...new Set(delta.map(d => d.prop))];
    this.setState({ changes: target, buf: {} }); this.scanSoon();
    this.toast((back ? 'Desfeito: ' : 'Refeito: ') + (props.length === 1 ? props[0] : props.length + ' propriedades'), 'ok');
  }
